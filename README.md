# ازدهار — تطبيق Flutter للتوكيدات اليومية

تطبيق عربي يضم جلسات الصباح والمساء والليل وتوكيدات المال والوفرة وبرمجة العقل الباطن والآيات القرآنية، مع تسجيل القراءة والإنجاز والتذكيرات.

## حالة المستودع
تمت إضافة GitHub Actions لبناء APK، لكن يجب رفع ملفات المشروع المصدري أولاً.

## رفع المشروع
1. فك ضغط ملف `izdihar_flutter_build_ready.zip` من المحادثة.
2. اختر **Add file → Upload files** من صفحة المستودع.
3. ارفع الملفات والمجلدات بعد فك الضغط، مع الحفاظ على مسارات `lib/` و`assets/` و`tool/` و`test/` و`pubspec.yaml`.
4. يُفضّل عدم استبدال الملف `.github/workflows/build-apk.yml` الموجود.

## إصدار APK
افتح تبويب Actions ثم Build Izdihar Android APK. سيبدأ البناء عند رفع الملفات إلى main، أو يمكن بدء البناء يدوياً.
بعد النجاح اختر أحدث Run ثم Artifacts → Izdihar-Android-APK لتحميل APK.

**تنبيه:** لم يتم اختبار بناء APK على جهاز Android بعد؛ إن فشل البناء يُراجع سجل Actions.
