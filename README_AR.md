# اِزْدِهَار — Izdihar Flutter

تطبيق Flutter عربي (RTL) لتوكيدات المال، والطمأنينة، وتدبّر آيات مختارة، بتصميم داكن مع لمسات ذهبية وألوان بحسب جلسات اليوم.

## محتوى النسخة

- **3 جلسات:** الصباح، المساء، الليل.
- **116 نصًا** مأخوذًا من المادة المرسلة، محفوظة في `assets/content.json`.
- **3 مجموعات داخل كل جلسة:** توكيدات المال، توكيدات العقل الباطن، وآيات قرآنية. الآيات تضم الرزق والمحبة والتوفيق وعلو الجاه والمكانة.
- زر **تمت القراءة / تم التدبر** بجانب كل نص، ويمكن التراجع عن التأشير.
- زر **أنهيت الجلسة** لتسجيل اكتمال الجلسة وإيقاف إشعاراتها المعلقة لذلك اليوم.
- حفظ تلقائي محلي (بدون حساب) لقراءات كل يوم، الجلسات المكتملة، والمفضلة.
- إحصاءات إنجاز أسبوعية، وعدّاد أيام الالتزام المتتابع.
- تنبيهات في الأوقات التي يحددها المستخدم، ثم تذكير لاحق عند عدم إنهاء الجلسة.
- يعمل المحتوى وحفظ الإنجاز بدون اتصال، مع ملاحظة أن تحميل خط Cairo من Google Fonts قد يحتاج إنترنت في أول تشغيل.

## متطلبات التشغيل

- **Flutter SDK 3.38.1 أو أحدث** مع **Dart 3.10 أو أحدث**.
- Android Studio لتطوير Android، و Xcode على macOS لتجميع iOS.
- Android SDK Platform 36 و Java 17 (لإضافات الإشعارات المختارة).

> لا يحتوي الأرشيف على Flutter SDK، أو Android/iOS platform boilerplate المُولَّد آليًا؛ يقوم سكربت التهيئة بإنشائها بإصدار Flutter الموجود عندك، ويضبط صلاحيات الإشعارات وملفات Gradle.

## التشغيل — Windows / macOS / Linux

داخل مجلد المشروع في Terminal:

```bash
python tool/bootstrap.py
flutter run
```

**إن لم يعمل الأمر `python` على Windows:** استخدم `py tool/bootstrap.py`.

يمكن بعد ذلك بناء APK:

```bash
flutter build apk --release
```

وسيكون الناتج عادة في `build/app/outputs/flutter-apk/app-release.apk`.

## آلية الإشعارات

المواعيد الابتدائية الافتراضية: 07:00 صباحًا، 05:30 مساءً، 10:00 ليلًا. يمكن تعديلها من الإعدادات، وكذلك تعديل مهلة إعادة التذكير (15–90 دقيقة).

- عند بدء التطبيق، تُجدول إشعارات الجلسات لـ **10 أيام قادمة**: تنبيه أول ثم إعادة تذكير.
- بالضغط على الإشعار، يفتح التطبيق جلسة الصباح أو المساء أو الليل الخاصة به (في حال دعم النظام لذلك).
- عند الضغط على **أنهيت الجلسة**، يُلغى التنبيهان الخاصان بالجلسة لهذا اليوم. إن ألغيت علامة اكتمالها، تُعاد الجدولة.
- يتم تحديث الجدولة عند فتح التطبيق أو عودته إلى الواجهة. العدد الأقصى في الأفق الواحد 60 تنبيهًا؛ وهذا يناسب حد iOS المعتاد البالغ 64 تنبيهًا قيد الانتظار.
- **حدود معروفة:** إذا لم تفتح التطبيق أكثر من 10 أيام، يجب فتحه لتجديد التذكيرات؛ وتوقيت إشعارات Android غير دقيق إلى الدقيقة بسبب `inexactAllowWhileIdle` وتوفير البطارية. لا تُضمن الإشعارات إن رُفض إذن النظام أو فعّل الهاتف قيود توفير الطاقة. تذكير عدم الإكمال هو تنبيه مُسبق الجدولة يُلغى عند إكمال الجلسة، وليس خادمًا يراقب الاستخدام عن بُعد.

### تعديل الصلاحيات يدويًا

يُضيف `tool/bootstrap.py` إلى AndroidManifest:

- `android.permission.POST_NOTIFICATIONS`
- `android.permission.RECEIVE_BOOT_COMPLETED`
- `ScheduledNotificationReceiver` و `ScheduledNotificationBootReceiver`

كما يفعّل Java desugaring ويضبط Gradle/Java بما يناسب إضافة الإشعارات. **بناء iOS** يتطلب بيئة macOS وتهيئة التوقيع الخاص بجهازك داخل Xcode.

## ملاحظات المنتج

- لا يتضمن تسجيل دخول، دفعًا، خادمًا، مزامنة بين الأجهزة، أو تسجيل صوت. البيانات على الهاتف فقط، وفقدان بيانات التطبيق يؤدي لفقدان السجل.
- الآيات القرآنية **مقتطفات للتدبر** دون أسماء السور كما طُلب، وليست توكيدات ولا وِردًا مسنونًا لهذه الأوقات. عند النشر التجاري يوصى بمراجعتها على مصحف معتمد وبإضافة مصدر كل مقتطف في شاشة معلومات اختيارية.
- لا توجد أدلة أن التوكيدات أو «الذبذبات» تجلب المال تلقائيًا. التطبيق وسيلة للتأمل والانضباط ومتابعة الأهداف.
- هذا **مصدر مشروع Flutter** وليس APK مجرَّبًا؛ تعذر إجراء `flutter analyze` أو بناء نسخة تشغيلية لأن Flutter SDK غير مثبت في بيئة إعداد الملف.
